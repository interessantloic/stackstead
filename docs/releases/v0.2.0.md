# Stackstead 0.2.0

这一版本重点重做了面向 PT 用户的流量面板，并建立完整的 90 天流量历史体系。

## 主要更新

- 新增四档上传与下载速率仪表盘，并记录每日峰值及发生时间。
- 默认上传色为 `#205DA6`、下载色为 `#0E8E3F`，可在设置中修改并全局同步。
- 新增 ASUS 风格的实色轮廓线与渐隐面积流量图，支持 30m、1h、6h、24h 范围和悬停详情。
- 新增今日流量、90 天历史累计和当前最活跃下载器卡片。
- 新增当日累计与实时速率下载器占比图，以及上传/下载排序排行榜。
- 新增最近 90 天每日明细，可查看全部或单个下载器的 24H 速率曲线。
- 下载器管理、流量配色和仪表盘上限统一移入设置页面。
- 流量累计改为按实际轮询间隔计算，停用下载器时也会保存最后一个待累计周期。
- 桌面端与移动端布局同步优化，移动端保留双仪表盘并排展示。

## 数据升级

SQLite 会在启动时自动创建每日汇总和峰值表，并从已有分钟采样回填最近 90 天数据。修改应用时区后，日汇总和历史峰值会按新时区重建。无需手工执行数据库迁移命令。

## 离线部署

Release 附件提供 `linux-amd64` 和 `linux-arm64` 两套离线 ZIP。每套均包含已经构建好的 Docker 镜像、Compose、`.env`、部署说明和 SHA-256 校验文件，适合无法访问 GHCR 或 Docker Hub 的 FNOS/NAS。
